# Mundial 2026 Dashboard

Modern Angular SPA for a FIFA World Cup 2026 overview: dark iOS-like visual style, group dashboard, and elimination ladder.

## Stack

- Angular 21 standalone application
- SCSS, no UI framework required
- Signal-based UI state
- Responsive dashboard and bracket layout

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200`.

## Build

```bash
npm run build
```

## Notes

Group data is stored in `src/app/tournament.data.ts`. Demo points are placeholders so the UI can later connect to a live data service.
